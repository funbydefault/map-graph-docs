# Map Graph

Map Graph is a native Unreal Engine plugin for deterministic branching progression maps.
Author rules, node types and presentation themes in the Editor, then generate and navigate
from Blueprint or C++.

[Read the customer guide](https://funbydefault.github.io/map-graph-docs/)

The guide covers Editor and Blueprint setup, mouse and keyboard, gamepad and touch input,
visual customization, route drawing, gameplay events, persistence boundaries, diagnostics,
migration and troubleshooting. This repository contains documentation only.

Version 1.3.0 targets Unreal Engine 5.4 through 5.8 on Win64.
